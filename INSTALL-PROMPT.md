# Installer-Prompt

Dieser Text steht auf der Downloadseite. Der Kunde kopiert ihn und fügt ihn in
Claude Code ein. Mehr bekommt er von uns zunächst nicht zu sehen.

Bewusst kurz gehalten. Die gesamte Logik liegt in `SETUP.md` und ist damit
versioniert. Ändert sich der Ablauf, bleibt dieser Text gleich.

---

```text
Richte mir bitte meine Claude-Arbeitsumgebung ein.

1. Lege einen Ordner "claude" in meinen Dokumenten an, falls er noch nicht
   existiert, und arbeite ab jetzt darin.
2. Hole dir das Starterkit mit:
   git clone https://github.com/startandconnect/starterkit
3. Lies starterkit/SETUP.md und arbeite sie vollständig mit mir durch.

Erkläre mir dabei jeden Schritt, bevor du ihn machst. Ich kenne mich mit
Technik nicht besonders aus.
```

---

## Hinweise für die Downloadseite

- Über dem Prompt gehört ein Satz, was gleich passiert und wie lange es dauert
  (etwa 10 Minuten).
- Darunter der Hinweis, dass Claude Desktop mit Claude Code installiert sein
  muss, plus Link zum Video.
- Der Kopieren-Button ist wichtiger als jede Erklärung daneben.
